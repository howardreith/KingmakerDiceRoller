# Licensing and distribution

Kingmaker Dice Roller source is MIT-licensed by Howie Reith.

The upstream Wrath dice roller was used as a behavioral reference for expression
and dice concepts. Its MIT notices are preserved verbatim in
`licenses/UPSTREAM-WOTR-DICE-ROLLER-MIT.txt`, and the relationship is described
in `THIRD-PARTY-NOTICES.md`.

No Pathfinder: Kingmaker executable, managed game assembly, Unity asset, icon,
screenshot, save, log, or decompiled source belongs in Git or the distributable
package. Local game assemblies are consumed only through ignored paths and are
identified by hash/MVID in ignored qualification evidence.

Harmony12 and Unity Mod Manager binaries are provided by the user's installation
and are not redistributed by this repository.
